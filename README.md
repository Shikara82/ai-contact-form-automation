## 🚀 Features

- 🌐 Capture website contact form submissions
- 🤖 AI-powered lead qualification
- 📊 Store leads in Google Sheets
- 📧 Automatic acknowledgment email
- 🔔 Instant team notification
- ⚡ Built with n8n

---

## 🏗️ Workflow

```text
Website Form
      │
      ▼
Webhook
      │
      ▼
AI Analysis
      │
      ├────────► Google Sheets
      │
      ├────────► Gmail Auto Reply
      │
      └────────► Team Notification
```
